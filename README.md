# MedAssist

MedAssist is a full-stack MERN clinic operations and patient care portal.

## Tech Stack

- MongoDB
- Express.js
- React
- Node.js

## Development Workflow

Backend → Database → APIs → Testing → Frontend → Integration

## Roles

- Clinic Admin
- Doctor
- Receptionist
- Lab Technician
- Patient
